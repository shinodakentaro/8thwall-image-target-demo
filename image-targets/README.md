### Image Target Data

Place generated image target JSON files here. Each file's internal `name`
field must match the `imageTarget.name` set on the corresponding object in
`src/.expanse.json` and the entry in `IMAGE_TARGET_NAMES` in `src/app.ts`.

Currently expected:
- `target1.json`
- `target2.json`

These files are NOT the raw source images — they are generated by 8th Wall's
image target processing tool from a source image (upload the photo you want
to recognize and it outputs the descriptor JSON used here). Generate them via
the 8th Wall Studio image target uploader, then drop the resulting JSON files
in this folder with the filenames above (or update the names in `app.ts` /
`.expanse.json` to match whatever you generate).

### Sample source images

`source-images/target1-source.png` and `source-images/target2-source.png` are
placeholder candidate photos (generated fractal patterns — high contrast,
asymmetric, feature-rich, which tends to track well). Upload these to 8th
Wall's image target tool to produce `target1.json` / `target2.json` for a
quick end-to-end test, or replace them with your own real target photos.
